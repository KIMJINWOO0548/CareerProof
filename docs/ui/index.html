워크벤치 사용 안내

가상의 지원서를 열어 둔 상태입니다. 실제 개인정보나 API 키를 입력할 필요가 없습니다. 새로고침하면 예제로 돌아갑니다.

  1. 작성할 근거 확인프로필과 사실 원장에서 역할·행동·성과가 원문과 일치하는지 확인합니다.
  2. 문항 편집과 수정안 검토작성 화면에서 본문과 분량을 확인하고 수정안의 근거를 비교합니다.
  3. 제출할 버전 확정선택한 문항을 확정한 후 내보내기 화면에서 파일 내용을 확인합니다.

글자 수 보정

각 예문을 제출 화면에 넣고 표시된 문자 수를 입력하세요. 예제에서 공백·줄바꿈·이모지 처리 후보를 좁혀 봅니다.

이 비교는 문자 수 규칙의 예시입니다. 작업 문항에는 화면에 표시된 예제 규칙이 적용됩니다.
